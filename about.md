# À propos de Gonfle-Taupe

**Gonfle-Taupe** est un jeu d'action-fouille souterraine développé par **Geoffroy Streit**
(alias **Hylst**).

## Le jeu

Un hommage libre au genre classique du mineur qui creuse ses propres tunnels pour piéger des
monstres : les gonfler à la pompe jusqu'à ce qu'ils explosent, ou leur faire tomber un rocher
dessus. Deux types de monstres, un système de combo, des légumes bonus et des power-ups.

Le nom joue sur la mécanique centrale (gonfler les ennemis à la pompe) et le thème
souterrain, sans reprendre le nom de la licence dont il s'inspire.

## Le créateur

- Développeur d'applications, ancien graphiste et compositeur
- Adepte de rétrocomputing et de demoscene

## Stack technique

- React 19, TypeScript 5.9 (strict), Tailwind CSS 4
- Vite 7, vite-plugin-singlefile
- Logique de jeu (`game/gameEngine.ts`) entièrement pure, séparée du rendu Canvas 2D
- Web Audio API pour la musique et les effets
